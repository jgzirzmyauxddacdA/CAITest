One link. One prompt.

Enter a character link to generate an English prompt. Paste it into Codex to export existing chats and profile data. Definition is saved only when copying is allowed, without conversation recovery.

Supports https://character.ai/chat/… links, including those with a hist session parameter.

Your link is processed only on this page and is never uploaded. Generating a prompt does not start an export.

Use an agent that can run local commands. The workflow requires Git, uv, and Chrome. Complete login and any CAPTCHA yourself in Chrome. Non-copyable Definition is skipped; no test messages are sent.
